# Objective

A dataset of **Retail** Data is cleaned and **Exploratory Data Analysis** is performed. This project is created on **Jupyter Notebook** and uses **Python** to manipulate the dataset by creating a dataframe. For visualisations **Matplotlib** and **Seaborn** is used.


## Customer Segmentation for Targeted Marketing

As a marketing analyst, I want to segment customers based on demographic information (age, gender, income) and purchasing behavior (total purchases, total amount spent) so that I can tailor marketing campaigns. So I have used **FacetGrid** to show the purchase behaviour of male and female high spenders on different income levels. I used **Grouped Bar Chart** to show the most high spenders in different age group and income level. Lastly, I used **Stacked Bar Chart** to show the high spenders based on gender and age group.

## Regional Sales Performance Analysis

As a regional sales director, I want to analyze sales performance by geographic location (city, state, country, and zipcode) to identify regions that underperform.
